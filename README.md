**Professor de Tecnologia da Informação | Desenvolvedor de Software | Empreendedor Digital**

Atuo na educação em Tecnologia da Informação desde 2005, integrando a experiência em sala de aula à criação de projetos de software e materiais para aprendizagem prática.

Meu trabalho reúne **programação, engenharia de software, bancos de dados, ciência de dados, inteligência artificial e desenvolvimento de jogos digitais**. ## 📚 Para quem está aprendendo programação

Se você está começando, recomendo explorar primeiro o repositório **[Python](https://github.com/andreolimpio/Python)**.

Uma boa sequência de estudo é:

1. Ler o problema e tentar elaborar uma solução antes de consultar o código.
2. Examinar a implementação e identificar as estruturas utilizadas.
3. Executar o exemplo em seu ambiente de desenvolvimento.
4. Modificar entradas ou regras e observar os resultados.
5. Registrar o que aprendeu e criar uma nova versão da solução.

A proposta é aprender não apenas **como escrever código**, mas também **como compreender, testar, organizar e aprimorar software**.
